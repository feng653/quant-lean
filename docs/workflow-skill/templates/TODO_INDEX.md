> 生效日期：由初始化决定 ｜ 与 GitHub issue 一一对应。issue 是任务真源，本文件是版本顺序的只读镜像。

> 更新者：仅协调者（从 issue 同步）。

## 无代码操作队列

- GitHub 配置（自托管 runner、API key secret、master 保护 ruleset 的 Required checks）——基础设施项，见 `docs/WORKFLOW_AUTOMATION.md`。

## 完成定义

代码项只有在：实现 → 测试 → PR 合入 → 版本验收（三层门禁全绿）→ 打 tag 后，才可标记 `完成`。
仅"代码存在"或"测试通过"不算完成。
