## 读取顺序

每次开始、完成、切换、handoff、合并、部署或恢复工作时，必须从磁盘重新读取本文件和
下列文件，不能依赖会话记忆：

1. 按版本号顺序读取所有 `CODE_TODO_*.md`；先完成最早版本中的第一个可执行未完成项。
2. 所有代码版本都完成、审查、合并并部署后，才读取并执行
   `EXPERIMENT_OPERATIONS_TODO_20260802.md`。
3. 每完成一项立刻重新从磁盘读取本索引及全部 TODO；只要仍有 `待开始`、`进行中`、
   `待验收` 或可解除的 `阻塞` 就继续。
4. 只有所有 TODO 都没有未完成项，或存在无法在当前授权范围内解除的外部阻塞，才可停止。

用户可直接修改这些文件。Agent 必须保留用户增加的项目、顺序、备注和验收标准；发现
运行中被修改时，以磁盘最新内容为准。需求过于发散时，先拆成方向单一的小版本再实施，
不得把无关改动塞进当前版本。

仅“代码存在”或“fixture 通过”不是完成。实验操作只有真实任务和持久化结果可核对时才可
完成。研究/模拟的数据风险默认告警，技术完整性错误仍阻断；未来实盘持续硬锁。
