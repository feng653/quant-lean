## 策略原理

LSTM (Long Short-Term Memory) 是处理序列数据的经典深度学习模型：

1. **序列输入**: 将每只股票的过去60个交易日的因子序列作为输入
2. **时间建模**: LSTM刻意设计"遗忘门"和"记忆门"，能从长时间序列中提取有意义的模式
3. **涨跌预测**: 训练LSTM预测下月该股票是涨还是跌
4. **排序买入**: 每月买入预测上涨概率最高的10%股票

相比传统机器学习(Gradient Boosting)，LSTM的优势：
- 自动学习因子之间的**时序依赖关系**
- 不需要人工构造"滞后项"特征
- 能捕捉**复杂非线性时序模式**

## 风险分析

### 优势
- **时序建模**: 理论上有能力捕捉技术分析策略无法捕捉的时序模式
- **端到端学习**: 不需要手动设计信号规则

### 风险点
- **过拟合风险极高**: 100只股票×60天序列样本量有限，复杂LSTM极易过拟合
- **黑盒不可解释**: 无法解释为什么某只股票被选中，实盘信心度低
- **训练不稳定**: 深度学习在金融数据上的收敛性远差于表格模型
- **数据量要求高**: 需要更多股票(500+)和更长历史(10年+)才有稳定效果
- **GPU依赖**: 虽然CPU可跑，但100个epoch在CPU上需要数小时

### 改进方向
- 增加股票数量(完整CSI 500的429只)
- 减小模型复杂度(1层LSTM + 高dropout)
- Walk-Forward验证 + Deflated Sharpe Ratio去偏
