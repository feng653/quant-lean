## 策略原理

与Alpha158+LightGBM共享相同的因子输入，但使用XGBoost作为替代模型。

**XGBoost vs LightGBM 的差异**：

| 特性 | LightGBM | XGBoost |
|------|----------|---------|
| 树生长方式 | 叶子优先 (leaf-wise) | 层级优先 (level-wise) |
| 速度 | 更快 (大数据集) | 稍慢 |
| 小数据集 | 容易过拟合 | 更鲁棒 |
| 缺失值处理 | 自动 | 自动 |
| 正则化 | L1/L2 | L1/L2 + 列采样 |

## 回测中的角色

这个策略作为**对照实验**存在——同样的因子输入，不同的模型，观察哪种树模型在A股上表现更好：

- 如果LGB和XGB结果接近 → 说明因子是关键，模型选择次要
- 如果两者差异很大 → 需要进一步分析原因(数据规模、过拟合等)

## 风险分析

同Alpha158+LGB的所有风险点，加上：
- **XGBoost对小数据集更保守**: 100只股票可能更合适
- **训练时间更长**: XGBoost的层级优先策略在相同参数下更慢
