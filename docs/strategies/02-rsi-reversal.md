# RSI均值回归策略 (RSI Reversal)

## 基本信息

| 属性 | 值 |
|------|-----|
| 来源 | [je-suis-tm/quant-trading](https://github.com/je-suis-tm/quant-trading) |
| GitHub Stars | ★ 10,400 |
| 类别 | 技术分析 — 均值回归 |
| 参数 | RSI周期=14, 超卖=30, 超买=70 |
| 信号逻辑 | RSI从超卖区回升(30→) → 买入; RSI从超买区回落(70→) → 卖出 |

## 策略原理

RSI (Relative Strength Index) 衡量价格变动的速度和幅度，范围0-100：

1. **超卖反弹**: RSI < 30 说明近期跌幅过大，可能超卖，预期反弹。RSI回升突破30时买入
2. **超买回落**: RSI > 70 说明涨幅过大，可能超买，预期回调。RSI回落跌破70时卖出

本质上这是一个"逆向投资"策略——在大多数人恐慌时买入，在大多数人贪婪时卖出。

## 风险分析

### 问题诊断
这是唯一一个在两个池子均为负收益的策略。原因：

1. **逆势交易**: 2024-2026年A股整体呈上涨趋势，RSI在牛市中会频繁进入超买区，策略不断卖出，错失上涨
2. **信号过多**: ~1,900个信号意味着频繁交易，手续费侵蚀利润
3. **均值回归不适合强势单边行情**: 在趋势市中"抄底"往往抄在半山腰

### CSI 800 表现优于 CSI 500 的原因
CSI 800 包含沪深300大盘股，波动性更小、趋势更缓，均值回归策略在大盘股上的表现天然优于波动大的中盘股。

### 风险点
- **趋势市致命**: 单边上涨时策略不断卖出，完全踏空
- **RSI钝化**: 极端趋势中RSI可长期维持在超买/超卖区
- **高换手**: 1,900个信号/100只股票，交易频率过高

### 改进方向
- 仅在大盘震荡行情中使用
- 增加趋势过滤器(牛市禁用、熊市或不参与)
- 缩减参数：超卖=20, 超买=80，减少假信号
