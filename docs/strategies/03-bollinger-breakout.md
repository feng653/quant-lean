# 布林带突破策略 (Bollinger Breakout)

## 基本信息

| 属性 | 值 |
|------|-----|
| 来源 | [je-suis-tm/quant-trading](https://github.com/je-suis-tm/quant-trading) |
| GitHub Stars | ★ 10,400 |
| 类别 | 技术分析 — 波动率突破 |
| 参数 | 窗口=20日, 标准差倍数=2.0 |
| 信号逻辑 | 价格突破上轨 → 买入; 跌破中轨 → 卖出(止损) |
| 止损优化 | 价格跌破中轨(20日均线)时强制平仓 |

## 策略原理

布林带由三条线组成：
- **中轨**: 20日移动均线
- **上轨**: 中轨 + 2倍标准差
- **下轨**: 中轨 - 2倍标准差

1. **突破买入**: 价格突破上轨意味着波动率扩张+方向向上，可能开启一轮趋势
2. **止损退出**: 价格回落跌破中轨说明动能衰竭，强制平仓保护利润

相比原始版本，加入了**中轨止损机制**，解决了之前版本"赚了不走、亏了不卖"导致的极端回撤问题。

## 风险分析

### 优势
- **CSI 800 回撤仅16.03%**: 加入止损后，大盘股组合回撤控制良好
- **Sharpe接近1.0**: CSI 800的Sharpe=0.996，接近可接受水平
- **及时退出**: 中轨止损在趋势反转时能保护大部分利润

### 风险点
- **信号量极大**: 5,000+信号/100只股票，换手率过高
- **CSI 500 回撤仍达30%**: 中盘股波动大，20日中轨作为止损线可能太宽
- **假突破**: 2倍标准差可能不够严格，很多突破为假突破
- **样本内过拟合风险**: 20日/2σ参数可能对2024-2026行情过拟合

### 改进方向
- 提高突破阈值：2σ → 2.5σ 或 3σ 减少假突破
- 收紧止损：中轨 → 买入价×0.95 固定止损
- 增加成交量确认：突破需伴随放量
