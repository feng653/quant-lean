# 风险平价策略 (Risk Parity)

## 基本信息

| 属性 | 值 |
|------|-----|
| 来源 | [robertmartin8/PyPortfolioOpt](https://github.com/robertmartin8/PyPortfolioOpt) |
| GitHub Stars | ★ 4,800 |
| 类别 | 组合优化 |
| 参数 | 回看63日, 月度再平衡 |
| 信号逻辑 | 每只股票权重 = 1/波动率 ÷ 总倒波动率 |

## 策略原理

风险平价的核心思想是：**每只股票对组合的风险贡献相等**，而非每只股票的仓位相等。

1. **计算波动率**: 基于过去63个交易日的收益率计算每只股票的波动率
2. **倒波动率加权**: 波动率越小的股票，权重越大(因为需要更多仓位才能贡献同等风险)
3. **月度再平衡**: 每月重新计算权重并调仓

这样做的效果：**自动偏向低波动股票**，在震荡市中降低组合回撤。

注意：这是一个**资产配置框架**而非选股策略。它不做alpha选股，而是对已有股票池进行风险分配。

## 风险分析

### 优势
- **被动风控**: 自动将资金分配给低波动股票，降低组合整体风险
- **无需选股**: 不依赖对个股的判断，纯风险维度
- **机构级方法论**: 桥水基金All Weather策略的核心思想

### 风险点
- **低波动陷阱**: 长期低波动的股票可能突然"爆雷"，历史波动率不能预测未来
- **动量缺失**: 仅关注风险不关注收益，可能错过强劲趋势股
- **再平衡成本**: 月度换仓产生交易成本
- **当前实现问题**: pandas新版pct_change API变化导致收益率计算异常

### 改进方向
- 修复pandas兼容性问题
- 结合动量因子：在低波动股票中选强势的
- 加入最大权重限制：防止单一股票占比过重
