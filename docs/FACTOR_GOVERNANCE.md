# 因子研究定位、组合方法与治理

> 产品方向：独立因子工作台；方便做单/多因子实验并可信导出到策略池。
>
> 实施计划：[v0.2.6](todo/CODE_TODO_v0.2.6_20260802.md)；自定义公式只作为未来候选，
> 尚未排期。

## 当前能力与缺口

现有页面已有 IC/RankIC、衰减、分层收益、换手/成本/容量、相关矩阵、中性化、顺序正交、
稳定性和版本化导出基础；完成运行在 `factor_research_runs` 保存定义、请求、结果、数据摘要、
用户和任务身份，核心字段由 SQLite trigger 保护。

当前不足不能被文档掩盖：运行仍依赖旧 DataCache 而不是活动 ResearchDataStore；目录只有
少量硬编码因子；前端没有真正的多因子组合编辑器；稳定性主要针对主因子；现有导出契约
可能组合不同 generation、运行或窗口的证据。v0.2.6 优先关闭这些可用性和可信导出缺口。

## 推荐组合方法

### 默认：等权百分位总分

对每个交易日的横截面依次完成：输入可用时点校验 → 去极值 → 缺失处理 → 可选行业/规模
中性化 → 方向对齐 → 百分位 rank。多个因子按等权平均得到总分，默认选前 10 只，并在
下一交易日执行。方法直观、尺度不敏感、样本要求较低，是个人研究的默认值。

### 进阶一：固定人工权重

用户明确给出非负或允许的方向权重，规范化后在开发、验证、锁定和模拟期间冻结。权重、
理由和修改版本必须留证，不能看完验证结果后原地调权。

### 进阶二：训练期 RankIC-IR 建议权重

只使用预注册训练窗口估计 RankIC 均值/波动，形成建议权重；单因子上限 40%，向等权收缩，
然后在验证、锁定和模拟期冻结。若样本、横截面或稳定性不足则回退等权并告警，不能滚动
偷看验证/模拟结果重新定权。

v0.2.6 不引入动态滚动 IC 权重、均值方差/风险预算、PCA、复杂集成或任意 Python。这些
方法增加估计误差、前视和解释成本，不适合当前“先稳定可用”的单一版本方向。

## 可信组合运行与导出

一个导出必须来自单次明确的多因子组合运行，并固定：

- active generation、来源、股票池、开发/验证/锁定窗口和代码 hash；
- 因子 ID、版本、定义摘要、方向、字段依赖、lookback 和 available lag；
- 去极值、缺失、中性化、正交顺序、组合方法和冻结权重；
- 调仓频率、执行延迟、成本、容量、top-k 和所有结构化数据告警；
- 组合级 IC/分层/衰减/换手/成本/容量/相关性/稳定性与边际贡献。

禁止把不同运行、generation、窗口或成本假设的单因子结果任意拼成“证据”。发布在
`BEGIN IMMEDIATE` 事务中重新读取运行原文并校验摘要；策略版本、证据、当前指针、幂等键
和审计事件原子提交。后续改变因子或权重必须发布新策略版本；回滚只切换当前指针，历史不改。

## 因子扩展

v0.2.6 继续使用代码随包交付的声明式目录：稳定 ID/语义版本、参数 JSON Schema、字段依赖、
方向、频率、lookback、available lag、单位、预处理和适用股票池。相同
`factor_id@version` 的定义摘要变化必须拒绝，不能覆盖历史。

未来如单独排期，可提供受限公式 DSL/可视化构建器，只允许白名单
lag/rolling/rank/算术，通过 AST、hash、单位和可用时点检查；禁止任意 Python、模块
导入、文件/网络和未来引用。它不是 v0.2.6 验收项。

## 参考实现与研究方向

- [Microsoft Qlib](https://github.com/microsoft/qlib)：数据集、表达式、记录器、策略和 PIT
  数据设计参考；本项目不直接引入其完整运行时。
- [Alphalens](https://github.com/quantopian/alphalens)：因子收益、IC、分层、换手和 tear sheet
  参考；其维护状态和默认市场假设不代表可直接替换本项目执行语义。

这些项目用于方法和接口学习，不构成对数据源、收益或实盘适用性的背书。
