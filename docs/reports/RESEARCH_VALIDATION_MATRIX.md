## Readiness Rules

- `blocked`: required data/runtime/no-future contract failed.
- `synthetic_only`: checks passed only on explicitly synthetic data.
- `cached_real_untrusted`: cached real data passed runtime checks but quality, provenance, or PIT lineage is incomplete.
- `cached_real_validated`: cached real data passed all gates and has a point-in-time universe claim.
- Non-PIT preset index pools can never be marked `cached_real_validated`.
