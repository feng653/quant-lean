# 量化数据链路与实盘安全审计

> 审计日期：2026-07-28
> 审计范围：`D:\doc\pi` 的数据获取、缓存、股票池、特征与标签、训练验证、
> 参数选择、回测撮合、研究晋级、模拟部署、任务调度、认证授权及未来券商边界。
> 审计结论：**未通过实盘认证（not certified）**。平台当前只允许研究与模拟，
> 不得连接真实资金账户。

## 1. 结论

本轮改造已经建立了比原型阶段严格得多的可信研究骨架：不可变数据与运行清单、
锁定测试集、训练模型补充证据、模型文件哈希、研究晋级状态机、缓存前复权一致性
检查、模拟任务提交幂等和机器可读实盘就绪闸门。新的失败路径大多采用 fail-closed
语义：证据缺失、哈希不符、数据质量致命、验证窗口不一致时停止晋级或执行。

这些改造**不能把现有历史结果追认为可信实盘证据**。本地股票池仍不是
point-in-time，旧前复权缓存存在跨股票池同代码同日期价格冲突，上市、停牌、ST、
涨跌停和退市状态没有完整点时数据；模拟盘也没有与回测及未来券商共用同一个成交
状态机。因此：

- 现有历史实验统一视为 `historical_only / non-promotable`。
- 现有 `data/cache` 必须在新缓存协议下受控全量重建，不能静默沿用。
- 当前可部署到真实资金的策略数量为 **0**。
- QMT/PTrade 仅是边界预留；当前没有被认证的实盘委托、撤单或成交回报入口。

## 2. 安全目标与威胁模型

审计以以下不变量作为准入标准：

1. **时间正确性**：任一预测只能读取预测时点已知的数据、成分股和公司状态。
2. **身份完整性**：实验、数据快照、代码、参数、模型和部署之间可哈希绑定，
   任何替换、跨用户引用或撤销都必须令执行失败。
3. **验证隔离**：训练、验证和锁定测试的职责不可混用；参数扫描不得在最终测试集
   上排名，验证指标必须按日横截面计算。
4. **执行保真**：目标仓位到订单、成交、费用和持仓的语义在回测、模拟和实盘一致，
   且能表达不可交易、部分成交、拒单、撤单和对账差异。
5. **故障安全**：重复请求、进程崩溃、任务重试、权限撤销和证据篡改不会产生重复
   交易或绕过闸门。
6. **可复现性**：独立环境能够根据不可变清单精确重建输入和结果，并识别 dirty
   代码、依赖、随机种子、线程、硬件及成本配置。

考虑的攻击与失效包括：幸存者偏差、复权拼接、缓存投毒、未来函数、验证泄漏、
过拟合选择、模型文件替换、IDOR、权限降级后的任务重试、重复调度、进程崩溃、
过期行情、券商重复回报、序列化模型 RCE 和密钥泄露。

### 4.2 前复权价格冲突

按 2026-07-28 当前文件重新读取四个 Parquet，并对共同日期、共同
`(证券, OHLCV字段)` 的有限值做逐单元格精确比较：CSI300/CSI800 有 8,933 个
差异，CSI500/CSI800 有 89,494 个差异，合计 **98,427** 个跨股票池冲突。
例如 `000937` 在 CSI500 缓存中从 2018-12-28 收盘 `-0.30` 跳到
2019-01-02 的 `1.82`，产生约 `-706.7%` 的伪收益；CSI800 同期为
`1.83 → 1.82`。最新只读矩阵在 CSI500 的 OHLC 字段中统计到 377 个负价格
单元格；其中此前专项核对发现 95 个非正收盘价。

缓存 schema v4 已绑定逐批来源证据与最终 frame digest；本轮继续补上价格内容
门禁和显式价格账本用途：

- 拒绝把 schema v1/v2/v3 或来源证据无效的缓存当作安全命中；
- 拒绝非有限/非正 OHLC、负成交量、部分 OHLC、OHLC 高低逻辑错误、重复日期和
  未来日期，禁止通过 clip、填零或静默去重“修复”；
- 要求所有请求代码完整覆盖、来源和复权口径单一；增量更新继续比较重叠窗口；
- 受控刷新先验证临时结果，全部通过后才原子替换，失败保留旧缓存；
- 公共研究刷新使用双源核验的 `hfq` 账本，明确标为
  `adjusted_return_research`；它不会被标成 raw 执行价格；
- readiness 独立返回普通可读、收益研究、执行模拟和无幸存者偏差调优四类状态。

这是**未来保护**，不是旧数据修复证明。现有四个 schema 3 qfq 文件仍是不可信旧
缓存，必须通过 `/api/data/update?pool_id=...` 逐池受控重建并生成新
`DatasetVersion`，重建前不得重新评估历史收益。即使价格重建成功，指数历史成分
时间线仍缺失，因此预设指数池及自定义静态列表的
`ready_for_unbiased_tuning` 必须为 false；不得把当前成分或今天挑选的代码回填
历史后称为无幸存者偏差研究。

### 4.3 缺失值与证券生命周期

只读矩阵统计的 OHLCV 缺失单元格分别为：CSI300 667,284（13.74%）、
CSI500 1,409,712（19.49%）、CSI800 2,087,370（18.00%）、CSI1000
3,063,012（23.53%），四池合计 7,227,378。
当前系统无法可靠地区分“尚未上市、正常停牌、已退市、供应端缺数”。回测估值可
长期沿用最后收盘价；复现实验中，退市后连续两日缺价的持仓仍按 10 元计值。

在加入点时证券状态表以前，缺失值不能只作为 warning。持仓证券失去报价必须触发
明确策略：暂停估值、使用有依据的清算价、退市处理或阻断结果，且处理方式写入
RunManifest。

### 4.4 现有数据库血缘

以只读、immutable 模式检查当前 `data/experiment.db`：共 284 个实验，其中 260 个
cancelled、24 个 completed；仅 12 个记录 `data_version`，仅 1 个记录
`code_version`。当前实际数据库还没有新代码定义的 research workflow / promotion
表，说明正在运行的旧服务尚未执行新迁移。`trading_sim.db` 当前包含 9 个部署、
2 个组合、28 次模拟运行和 348 个订单。

这批记录不得因代码升级而被自动视为满足新协议。部署升级必须先备份数据库、停止
旧 worker、在副本上演练迁移，再把历史实验和部署显式标记为 legacy/unverified；
不能为缺失血缘补写推测值。

## 5. 研究正确性审计

### 5.1 ML 横截面验证

选股模型的 IC/RankIC 应在每个预测日、跨证券计算，然后对有效日期聚合均值、
标准差和 ICIR。把所有日期和证券压平会混入市场时序趋势并造成 Simpson 悖论。
构造样例中，每日 RankIC 都是 `-1`，压平后却可得到 `0.6`，普通 IC 约为
`0.9998`。

准入实现必须满足：

- 每日独立对齐 `prediction/label`；
- 每日至少有保守的有效横截面样本数；
- 记录有效日期数、最小横截面、mean/std/ICIR；
- NaN、常量截面和证据不足 fail-closed；
- 指标与实际 `TrainCycle.pred_date`、训练/验证窗口、模型哈希绑定；
- 服务端阈值不可由客户端调低到允许负 RankIC。

本轮已完成上述门禁：至少 5 个有效预测日、每日至少 20 只股票；RankIC 服务端
硬下界 0.01、默认 0.02。模型晋级补充证据升级为 v2，旧 v1 证据不会被自动追认。
Simpson 负向用例中，旧压平 Pearson/RankIC 为 0.9998/0.6，新逐日结果均为 -1。

### 5.2 训练后备模型

LSTM/Transformer 在深度学习依赖缺失时可使用 sklearn fallback 方便开发，但此类
模型不能冒充目标架构进入研究晋级。本轮已把 backend/fallback 类型写入不可变证据，
并对 fallback、状态篡改、文件篡改统一阻断。`joblib`/PyTorch pickle 仍属于受信
边界内反序列化，未来实盘应优先采用 `safetensors`、ONNX 等非可执行格式。

### 5.3 参数选择与稳健性

平台已经区分调参 trial 与锁定测试，并要求显式手工晋级。新增稳健性接口计算
Bootstrap 置信区间、PSR、DSR 和 PBO，但结果被正确标记为
`post_hoc_diagnostic`、`selection_eligible=false`、
`promotion_eligible=false`。这避免把事后统计包装成独立测试证据。

尚未完成的硬门槛包括：预注册候选空间、失败/取消 trial 的候选计数语义、成本压力、
容量曲线、参数稳定区、多重检验和独立的 out-of-sample 再确认。当前本地实验库曾
出现 260 个 cancelled、24 个 completed trial；只以完成项作为候选数会低估选择
偏差。

## 6. 回测、模拟与部署审计

### 6.1 成交模型

执行引擎已从隐式月初清仓改为策略目标仓位语义，并加入成交量参与率和部分成交。
但仅依赖有效开盘价和成交量仍不足以模拟 A 股：一字涨停样例依然可能成交。实盘前
必须让统一执行核心读取点时停牌、ST、板块涨跌停规则、除权除息、最小交易单位和
可用资金，并支持拒单、部分成交、撤单、超时及交易所回报乱序。

### 6.2 成本与容量

研究晋级不得允许零佣金、零滑点、零印花税、零最低佣金或未设置成交量参与率。
税费的历史变化必须按成交日配置，不能用今天的固定费率回填十年前。容量验证至少
应输出参与率阶梯下的收益、换手、冲击成本和无法成交比例。

### 6.3 部署身份

安全链路必须是：

```text
DatasetVersion + UniverseSnapshot + Git/Environment
  → RunManifest
  → locked-test Report
  → approved ResearchPromotion
  → immutable model evidence
  → SimulationDeployment
  → 每次运行重新校验未撤销与哈希一致
```

只保存 `experiment_id` 或复制参数不够。部署激活和每次运行都要重新检查所有者、
晋级状态、撤销状态、报告/清单/模型哈希；撤销后已有部署必须立即停止。暂停草稿可
用于编辑，但不能在缺少晋级证据时激活或运行。

### 6.4 幂等与崩溃恢复

模拟运行现在使用原子 `BEGIN IMMEDIATE` claim、唯一订单意图、claim token 和同一
事务内账本/完成状态提交，能阻止并发重复请求及旧 worker 覆盖新结果。仍需对后台
job 做同等级别治理：

- retry 重新检查**当前**权限，而不是继承原请求权限；
- 同一 parent/attempt 只允许一个有效重试；
- 取消检查必须早于数据写入、训练产物替换和模拟成交（本轮已补操作前检查，
  长操作内部仍需继续提供协作式检查点）；
- 进程重启的 at-least-once 恢复必须配合业务幂等键；
- 当日数据更新失败或行情日期未推进时，调度器不得继续模拟。

## 7. 应用与基础设施安全

### 7.1 已具备

- 生产模式拒绝默认或过短 JWT secret；
- 主要 API 有权限与 owner 过滤；
- 模型、训练数据包和 RunManifest 使用 SHA-256；
- 清单拒绝 secret-like key 和本机绝对路径；
- 远程训练 token 只保存哈希，并有过期时间和上传大小限制；
- WebSocket bearer JWT 已从 URL 迁移到限时第一数据帧，完成 token 类型、活跃用户、
  RBAC 和 owner 检查前不订阅资源；URL 查询凭据被拒绝且应用/Uvicorn 日志纵深脱敏；
- 实盘就绪接口为机器可读 fail-closed 报告，前端显示“实盘锁定”且无真实下单路由。

### 7.2 实盘前必须完成

- refresh token 单次轮换、吊销、登出和会话设备审计；
- 首管理员引导事务化，失败 token 不得占用首用户名额；
- 登录/敏感 API 限流、MFA 和完整安全审计日志；
- WebSocket 慢客户端全部使用有界队列并具备背压/丢弃策略；
- PostgreSQL/独立对象存储、备份加密、RPO/RTO 和恢复演练；
- QMT/PTrade 独立凭据保管、最小权限进程和紧急停机；
- client order id 幂等、委托/撤单/成交回报状态机和每日三方对账；
- 资金、仓位、行业、单票、频率、价格偏离和日损失硬限额；
- broker adapter 认证测试、仿真故障注入、断线重连与人工回滚演练。

### Medium：结果解释和运维可靠性

- 已实现与未实现交易的收益、胜率、profit factor 分开呈现。
- 基准净值按实验初始资本显示，并要求相对指标证据。
- DSR 候选 Sharpe 的无风险利率口径统一，取消/失败候选按预注册协议计数。
- 因子计算显式 `fill_method=None`，并按交易状态 mask。
- LSTM/Transformer 标签 horizon 与参数一致。
- SQLite 连接参数统一，生产迁移到支持并发与恢复的数据库。
- MD5 参数标识迁移到 SHA-256（只读兼容旧记录）。
- `requirements.txt` 中仍有多项 `>=` 浮动依赖；RunManifest 虽记录实际版本，
  仍需按 Windows/macOS、CPU/CUDA 分别生成带哈希的 lock/constraints，才能复建
  相同二进制环境。
