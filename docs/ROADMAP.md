## 1. 产品边界

### 1.1 当前主路径

```text
可恢复数据 → 活动研究代 → 可解释实验 → 一键模拟观察
      → 每日真实模拟/次晨清单 → 因子与组合研究 → 持续观察和恢复
```

- 探索研究和模拟盘：来源、PIT、覆盖、跨源冲突、双价格口径及 promotion 状态是醒目、
  可追溯的风险提示，默认不因可信度等级不足而阻断。
- 技术完整性：无可计算数据、artifact/schema/hash 损坏、参数或模型身份不一致、事务失败、
  账本不守恒、重复执行无法判定仍必须阻断。
- 未来实盘：暂停且硬锁；研究/模拟的“告警后继续”绝不自动获得实盘资格。

### 1.2 模拟盘定位

模拟盘不是静态展示页。它应按实际交易日每日计算策略参数和信号，收盘后列出下一交易日
早盘的具体操作（证券、买卖方向、目标数量/权重、预计金额、原因、限制和无法执行项），
并用价格、持仓、现金和成本变化解释每日收益。净值、回撤、风险、换手、成交、暴露、基准
和对账数据都应可追溯。

策略组合一旦部署即形成不可变版本：子策略、权重、参数、模型、数据代、价格口径和风险
快照不得原地修改。任何调整都发布新版本，旧版本继续可复现，避免中途策略突变或持仓突变。

### 1.3 因子研究定位

因子研究是独立工作台，而不是普通实验表单的附属页。它支持声明式新增因子、单因子与
多因子组合实验、IC/RankIC、分层收益、衰减、换手、成本、容量、覆盖、缺失、中性化、
正交、相关性、稳定性和边际贡献分析，并把可信的组合运行直接导出到策略池。

默认组合方法是截面去极值/排序、方向对齐、等权百分位总分；高级但可解释的方法包括固定
人工权重，以及仅在训练期估计、设上限并向等权收缩后冻结的 RankIC-IR 权重。动态滚动
权重、复杂黑盒集成和任意 Python 不进入首版，以降低前视、过拟合和不可复现风险。

### v0.2.4 — 实验一键加入模拟观察

方向：把普通用户从实验到 paper 的必需操作压缩为“一次风险确认”，复杂 promotion 留在
高级研究治理中。

状态：**进行中**。

#### 当前流程问题

严格 research promotion 后端状态链是：研究假设/实验组 → selection trials → 人工 sweep
晋级 → locked-test 实验 → 不可变 final report → promotion draft → reviewed → approved/
rejected/revoked。它适合审计严格研究晋级，却缺少完整前端工作台；普通实验部署表单仍暴露
`research_promotion_id`，文档又把批准写成模拟的统一前置，用户必须理解内部 ID、报告和
状态机，操作成本与个人 paper 风险不匹配。

#### 目标默认流程

1. 在已完成实验中点击“加入模拟观察”。
2. 系统校验 artifact、策略、参数、模型和数据身份，自动派生不可变部署绑定。
3. 没有模拟组合时自动创建“我的模拟观察”；只有一个时自动选择；多个时才让用户选择
   目标和权重。
4. 用户阅读数据质量、过拟合、成本、容量和 promotion 可信度提示后确认。
5. 部署记录与新组合版本原子提交；其他模拟组合不改变。

promotion 缺失、未批准或撤销只降低 paper 可信度并持续告警，不阻断模拟观察。严格 promotion
状态机、报告和批准仍保留为高级证据，不能自动伪造；live 始终硬锁。旧部署 API 保持兼容。

## 6. 发布纪律

固定顺序：静态检查 → 单元/集成 → 前端测试/build → 审查 → 合并 `master` → 部署 →
部署后 API/健康/网络边界验证。版本号遵循 SemVer：兼容修复为 patch，兼容能力为 minor，
只有明确不兼容契约才升 major。仓库文件数、端点数和测试数不写死，以当前代码、OpenAPI、
运行报告和 CI 产物为准。
